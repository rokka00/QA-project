# Salahny Mobile App 🚗
A Flutter-based mobile application for car services and maintenance.

## 📱 Features
* Home Page UI
* Services Page
* Packages Page
* Profile Management
* Fix It Nearby (Map View)
* OBD Data Upload
* Customer Service Chat
* Repair Status Tracking
* Report & Problem System

## 🛠️ Tech Stack
* Flutter (Dart)
* UI/UX Design (Custom)
* Navigation System

## 🎯 Purpose
This project was developed as part of a Software Quality Assurance (SQA) and mobile development practice to simulate a real-world car service platform.
